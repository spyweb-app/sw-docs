Ready-to-run examples covering the patterns real jobs need. Each page pairs a `config.toml` with the Lua hooks that drive it.

- [Pagination](pagination/) - Cycle through pages using Lua globals.
- [JavaScript Rendering](javascript-rendering/) - Render JS-heavy pages with CDP browser automation.
- [Custom Data Extraction](custom-data-extraction/) - CSS selectors + Lua pattern matching for complex data.
- [Custom Filtering](custom-filtering/) - Replace built-in keyword filter with Lua logic.
- [Custom Fetch with Retry](custom-fetch-with-retry/) - Proxy failover, retry logic, and jitter.
- [External API Integration](external-api-integration/) - Skip internal DB, send items directly to your API.
- [Multi-Worker Queue](multi-worker-queue/) - DB-driven URL queue with atomic worker coordination.
- [Human in the Loop](human-in-the-loop/) - Recovery flow for blocked scrapers with manual intervention.
